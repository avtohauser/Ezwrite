# avr ezwrite — текст как от руки

Веб-инструмент экосистемы avr, который превращает напечатанный текст в рукописный — **вашим почерком, почерком друга или рукописным шрифтом**. Работает прямо в браузере, без сервера и регистрации.

## Как запустить

Откройте `index.html` в браузере. Чтобы заходить с iPad или телефона по ссылке, включите GitHub Pages: *Settings → Pages → Deploy from branch*, выберите ветку и папку `/ (root)`. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как пользоваться

1. **Почерк.** Выберите встроенный, нарисуйте свой или загрузите чужой (раздел «Почерки»).
2. **Текст.** Вставьте текст. Переносы строк и абзацы сохраняются, длинный текст сам разбивается на страницы.
3. **Бумага.** Линейка, клетка или чистый лист; A4, A5 или школьная тетрадь; поля, абзацный отступ, эффект фото/скана.
4. **Ручка.** Цвет чернил, толщина, нажим.
5. **Живость.** Пресеты «Аккуратно / Обычно / Торопливо / Небрежно» или тонкая настройка: наклон, разный размер букв, прыжки над строкой, «уплывающие» строки, неровные чернила. «🎲 Переписать заново» — та же рукопись с другой случайностью.
6. **Сохранить.** PNG (по картинке на страницу), PDF или сразу печать.

### Свой почерк

«Почерки» → «Создать свой почерк». Есть два режима:

- **Листом (удобно на iPad).** На экране сразу клетки для всех букв набора — пишите в них Apple Pencil или пальцем, как в бланке. Всё сохраняется само; `+` в клетке — написать букву ещё раз, `×` — стереть. «Заполнить ещё раз» очищает клетки, и новые надписи добавляются как дополнительные варианты букв. Как только замечен стилус, касания ладонью и пальцем перестают рисовать — пальцем можно листать.
- **По одной букве.** Большое поле для одной буквы (удобно с мышкой):

- низ буквы ставьте на синюю линию, строчные пишите до пунктира, заглавные — до верхней линии;
- `Enter` — сохранить и перейти к следующей букве, `Shift+Enter` — ещё один вариант той же буквы, `Ctrl+Z` — отменить штрих, `←`/`→` — листать буквы;
- 2–3 варианта каждой буквы делают текст заметно живее: при письме варианты чередуются случайно;
- символы, которые вы ещё не нарисовали, берутся из выбранного запасного шрифта.

### Чужой почерк

- **От друга:** друг рисует буквы в EzWrite и нажимает «Поделиться», получается файл `.ezwrite.json`. Вы загружаете его кнопкой «Импорт почерка друга».
- **Шрифт:** любой рукописный `.ttf/.otf/.woff/.woff2` (например, сделанный по образцу почерка в Calligraphr) — кнопка «Загрузить шрифт».

Все почерки хранятся только в вашем браузере (`localStorage`). Чтобы перенести их на другое устройство, используйте «Поделиться».

## Структура

```
index.html       разметка и интерфейс
css/style.css    стили
js/core.js       генератор случайных чисел, наборы символов, хранилище почерков
js/render.js     раскладка текста, бумага, отрисовка букв
js/editor.js     мастерская почерка (рисование букв)
js/app.js        настройки, превью, библиотека, экспорт
```

Встроенные почерки подключаются из Google Fonts, PDF собирается библиотекой jsPDF с cdnjs. Для того и другого нужен интернет; без него остаются PNG и печать.

## Оформление

Интерфейс следует брендбуку avr: светлая тема — «Бумага» `#E9EFEF` с акцентом «Фиолетовый» `#5A4FC8`, тёмная — «Бирюза» `#0B4248`, «Туман» `#D3E3E4` и акцент «Розовый» `#F2A5C3`. Шрифты — Google Sans Flex / Roboto Flex, словесный знак — Outfit, знак — четырёхлучевая звезда с градиентом `#F2A5C3 → #5A4FC8`. Кнопки-таблетки, карточки без теней, волнистый прогресс. Тексты — на «вы», без восклицательных знаков и эмодзи.
